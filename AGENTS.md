# Repository Guidelines

SoftwareBaleia is a GitHub organization metadata repository. It contains profile documentation and brand imagery only; there is no executable application, dependency manager, database, Dockerfile, or Compose environment.

Keep changes limited to Markdown and intentional profile assets. Validate links and rendered Markdown, preserve image files referenced by `profile/README.md`, and do not add application scaffolding or Docker configuration. Use local Git for focused Portuguese commits only when publishing is requested.
